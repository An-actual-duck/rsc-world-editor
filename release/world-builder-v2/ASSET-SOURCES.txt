WORLD BUILDER 2 ASSET SOURCES
=============================

The exact pinned runtime provider supplies the compiled client/server and only
the runtime/default definition and rendering assets enumerated in the included
RUNTIME-ASSET-ALLOWLIST.txt. Their upstream provenance and redistribution terms
are recorded in PLAYER-ASSET-SOURCES.txt.

World-editor toolbar icon authorship, source, license, and modifications are
recorded in EDITOR-ICON-CREDITS.txt. Public packaging is blocked until that
record contains confirmed redistribution terms.

Repository-owned launchers, schemas, adaptive project tools, documentation, and
the runtime allowlist are built from the exact source commit recorded in
SOURCE-COMMIT.txt. The platform Java runtimes retain their included legal files.

No terrain, static placement data, layered world package, creator project, or
generated operational state is an asset of this release. Target world data is
discovered and copied from the user's compatible server; standalone empty data
is generated inside a new project after installation.
